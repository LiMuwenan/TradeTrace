### 2.1 默认配置（`server.bind_host: 127.0.0.1`）本机访问

启动：`python -m app.server`，等待约 8 秒。

```powershell
python -c "import time,urllib.request as u
for p in ['/api/health','/api/v1/health','/api/v1/market/stocks/snapshot','/api/v1/market/stocks?q=600519&limit=5','/api/v1/market/datasets']:
    t=time.time(); r=u.urlopen('http://127.0.0.1:8000'+p, timeout=60)
    print(p, r.status, f'{(time.time()-t)*1000:.0f}ms', r.read().decode('utf-8')[:260])"
```

实际输出（关键字段）：

`serverTime` 以 `Z` 结尾、`schemaVersion=1`，符合契约 §3。

### 2.2 行情接口（含区间限制、错误体）

```powershell
python -c "import time,urllib.request as u,urllib.error as e
for p in ['/api/v1/market/stocks/600519/kline?from=2026-01-01&to=2026-10-25',
          '/api/v1/market/index/sh000300/kline?from=2026-01-01&to=2026-10-25',
          '/api/v1/market/stocks/600519/kline?from=2016-10-25&to=2026-10-25',
          '/api/v1/market/index/000300/kline',
          '/api/v1/market/stocks/600519/kline?from=2026-10-25&to=2026-10-01',
          '/api/stocks?limit=2000']:
    t=time.time()
    try: r=u.urlopen('http://127.0.0.1:8000'+p, timeout=60); code=r.status; b=r.read().decode('utf-8')
    except e.HTTPError as x: code=x.code; b=x.read().decode('utf-8')
    print(p, code, f'{(time.time()-t)*1000:.0f}ms', b[:200])"
```

实际输出：

| 路径 | 状态 | 耗时 | 响应 |
|---|---|---|---|
| `/market/stocks/600519/kline?from=2026-01-01&to=2026-10-25` | 200 | 61ms | `{"schemaVersion":1,"code":"600519","market":"SH","raw":{"dates":[],"open":[],"high":[],"low":[],"close":[],"volume":[]},"qfq":{…},"hfq":{…}}`（三组均为六个空数组） |
| `/market/index/sh000300/kline?from=2026-01-01&to=2026-10-25` | 200 | 36ms | `{"schemaVersion":1,"code":"sh000300","name":"沪深300","market":"SH","dates":[],"open":[],"high":[],"low":[],"close":[],"volume":[]}` |
| `/market/stocks/600519/kline?from=2016-10-25&to=2026-10-25`（3652 天） | 422 | 32ms | `{"code":"RANGE_TOO_LARGE","message":"查询区间超过 3650 天，请缩小范围","detail":null}` |
| `/market/index/000300/kline`（缺市场前缀） | 400 | 32ms | `{"code":"BAD_REQUEST","message":"指数代码必须带市场前缀（如 sh000300），收到: 000300","detail":null}` |
| `/market/stocks/600519/kline?from=2026-10-25&to=2026-10-01`（from>to） | 422 | 7ms | `{"code":"VALIDATION_ERROR","message":"起始日期不能晚于结束日期","detail":null}` |
| `/api/stocks?limit=2000`（既有接口，回归） | 200 | 24ms | `[]` |

**数据为空的原因（非缺陷）**：本机 `data/meta.db` 的 `stock` 表 0 行，且 `F:\market` 无 Parquet 文件，因此
快照 `count=0`、搜索空、日K 空、数据集 `fileCount=0`。接口按要求返回 200 + 空数组，未造假值。
快照 `count` 与 `/api/stocks?limit=2000` 返回量级一致（均为 0）。

### 2.3 CORS 白名单

```powershell
python -c "import urllib.request as u
for o in ['http://127.0.0.1:8081','http://evil.example']:
    r=u.urlopen(u.Request('http://127.0.0.1:8000/api/v1/health', headers={'Origin':o}))
    print(o, r.status, 'ACAO=['+str(r.headers.get('access-control-allow-origin'))+']')"
```

实际输出：

```
http://127.0.0.1:8081 200 ACAO=[http://127.0.0.1:8081]
http://evil.example 200 ACAO=[None]
```

白名单来源回显 `access-control-allow-origin`，非白名单来源无该响应头。

### 2.4 局域网模式（`server.bind_host: 0.0.0.0`）

临时把 `config/config.yaml` 的 `bind_host` 改为 `0.0.0.0`，重启后：

```powershell
python -c "import urllib.request as u
for host in ['172.17.252.97','127.0.0.1']:
    r=u.urlopen('http://'+host+':8000/api/v1/health', timeout=10); print(host, r.status, r.read().decode('utf-8'))"
```

实际输出：

```
172.17.252.97 200 60ms {"schemaVersion":1,"status":"ok","name":"lianghua","version":"0.1.0","serverTime":"2026-10-25T06:52:50Z"}
127.0.0.1 200 16ms {"schemaVersion":1,"status":"ok","name":"lianghua","version":"0.1.0","serverTime":"2026-10-25T06:52:50Z"}
```

通过局域网 IP 访问快照：

```

```

结论：`0.0.0.0` 绑定对局域网地址生效（本机经 LAN IP 回环访问成功）。

## 3. 待用户验证

- **浏览器跨域实访**：若手机/其它设备从 `http://<LAN-IP>:8081` 发起请求，需先把该来源加入
  `config/config.yaml` 的 `cors_origins`（当前白名单只有 `127.0.0.1/localhost` 的 8000/5173/8081）。

## 4. 未完成与遗留

1. **股票字典为空**：需先执行既有 `/api/stocks/init`（baostock 拉取）或已有库迁移，快照才有内容；
   接口逻辑已按契约实现，无数据时返回 200 + 空数组。
2. **路由器固定 IP 未配置**：当前 WLAN IPv4 由 DHCP 分配（`172.17.252.97`），地址变化后客户端需重新填写。
3. **v1 未捕获异常**：仍走 FastAPI 默认 500 响应体（`{"detail": ...}`），未返回契约 §7 的
   `INTERNAL_ERROR`；计划未要求全局异常处理器，且会影响既有 `/api/*`，留待后续单独评审。
4. **服务端无缓存**：按设计 §14.5 不缓存；`/market/datasets` 每次触发文件扫描，客户端应低频调用。
