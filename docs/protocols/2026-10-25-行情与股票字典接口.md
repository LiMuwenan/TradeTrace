# 行情与股票字典接口协议 v1

> 状态：**待评审**（评审通过后才开始改代码）
> 参与方：`lianghua`（服务端，只读行情）↔ `everything`（客户端，交易记录/离线识别）
> 依据：`lianghua/docs/行情数据服务规划.md`、`everything/docs/交易记录与复盘产品规划.md`
> 生效范围：客户端**只允许**调用本文件的 `/api/v1` 前缀接口；`lianghua` 既有 `/api/*` 接口保持原样，不改造、不删除。

---

## 1. 总体约定

| 项 | 约定 |
|---|---|
| 传输 | HTTP/1.1，明文（仅家庭局域网/VPN 内使用），无鉴权 |
| 前缀 | 本协议所有接口以 `/api/v1` 开头 |
| 编码 | 请求与响应均 UTF-8；JSON 字段名 **camelCase** |
| 时间 | ISO 8601 **UTC**，形如 `2026-10-25T02:30:00Z`；仅交易/行情日期使用 `YYYY-MM-DD`（本地交易日，不带时区） |
| 金额/股数 | JSON number，不加千分位字符串；价格最多 3 位小数，金额最多 2 位小数，股数为整数 |
| 版本 | 每个业务响应用整数 `schemaVersion` 标识结构版本，本期固定 `1` |
| 排序 | 股票列表按 `code` 升序；行情序列按 `dates` 升序 |
| 空数据 | 一律返回空数组 + 正常状态码 200，**不得造假值、不得用占位记录** |
| 错误 | 统一错误体（见 §7），HTTP 状态码表达类别 |
| 流式 | 本期无 WebSocket / SSE |

**客户端硬性约束**：不拼接 `/api/*` 其它路径；不在代码里写死 IP；`baseUrl` 由用户在设置页填写（Android 端禁止 `localhost`）。

## 2. 接口清单

| 方法 | 路径 | 用途 | 客户端使用场景 |
|---|---|---|---|
| GET | `/api/v1/health` | 服务健康检查 | 设置页「连接测试」、启动探活 |
| GET | `/api/v1/market/stocks/snapshot` | 全量股票字典快照 | 离线导入时「名称 → 代码」映射、股票选择器 |
| GET | `/api/v1/market/stocks` | 股票搜索 | 新建股票时按代码/名称检索 |
| GET | `/api/v1/market/stocks/{code}/kline` | 单股区间日K（raw/qfq/hfq） | 个股详情 K 线、择时分位 |
| GET | `/api/v1/market/index/{code}/kline` | 指数区间日K | 基准对比、复盘报告 |
| GET | `/api/v1/market/datasets` | 数据覆盖与新鲜度 | 展示「数据截至 X 日」 |

## 3. 健康检查

```
GET /api/v1/health
```

响应 200：

```json
{
  "schemaVersion": 1,
  "status": "ok",
  "name": "lianghua",
  "version": "0.1.0",
  "serverTime": "2026-10-25T02:30:00Z"
}
```

- 只要进程可响应即返回 `ok`；不代表行情数据可用（数据新鲜度看 `/market/datasets`）。
- 客户端连接测试判定：HTTP 200 且 `status == "ok"` 且 `schemaVersion == 1`。

## 4. 股票字典

### 4.1 全量快照

```
GET /api/v1/market/stocks/snapshot
```

响应 200：

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-10-25T02:30:00Z",
  "count": 5230,
  "stocks": [
    { "code": "600519", "name": "贵州茅台", "market": "SH", "industry": "白酒" }
  ]
}
```

| 字段 | 类型 | 必填 | 语义 |
|---|---|---|---|
| `schemaVersion` | int | 是 | 固定 1 |
| `generatedAt` | string | 是 | 本次快照生成时间（UTC）。同一份缓存内容必须复用同一值，供客户端判断是否刷新 |
| `count` | int | 是 | `stocks.length`，必须与内容一致 |
| `stocks[].code` | string | 是 | **6 位数字代码**，无交易所前缀（`600519` 而非 `sh600519`） |
| `stocks[].name` | string | 是 | 证券简称，可能含 `XD/XR/DR/ST` 等前缀；行业为空时允许 `""` |
| `stocks[].market` | string | 是 | `SH` / `SZ` / `BJ` |
| `stocks[].industry` | string | 是 | 行业名；无数据为 `""`，**不填占位文案** |

约定：

- 全量返回，**不分页**（体积目标数百 KB）。
- 不包含价格、涨跌幅等易变字段。
- 数据源为空时返回 `count: 0`、`stocks: []`，仍返回 200。
- 快照覆盖 `stock` 表中全部可识别为 A 股的行；无法识别的代码跳过，不报错。
- 客户端按 `generatedAt` 决定是否刷新，不每次启动强制拉取。

### 4.2 搜索

```
GET /api/v1/market/stocks?q=茅台&limit=50
```

| 参数 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `q` | string | 是 | — | 代码或名称关键词（子串匹配）；`q` 为空或全空格时返回空数组，不返回全表 |
| `limit` | int | 否 | 50 | 1–200，超出按 200 处理；小于 1 按 1 处理 |

响应 200：

```json
{ "schemaVersion": 1, "count": 1, "items": [{ "code": "600519", "name": "贵州茅台", "market": "SH", "industry": "白酒" }] }
```

- `items` 结构与快照 `stocks[]` 完全一致。
- 搜索 `600519` 或 `sh600519` 均应命中同一行。

## 5. 行情

### 5.1 个股日K

```
GET /api/v1/market/stocks/600519/kline?from=2025-10-25&to=2026-10-25
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | path | 是 | 6 位数字，或 `sh600519` / `sh.600519`；服务端归一化 |
| `from` | string | 否 | `YYYY-MM-DD`，含边界；缺省=不设下界 |
| `to` | string | 否 | `YYYY-MM-DD`，含边界；缺省=不设上界 |

校验：

- 任一参数格式非法 → 400 `BAD_REQUEST`。
- `from > to` → 422 `VALIDATION_ERROR`。
- 两端都给且跨度 > 3650 天 → 422 `RANGE_TOO_LARGE`，`message` 提示缩小范围。

响应 200：

```json
{
  "schemaVersion": 1,
  "code": "600519",
  "market": "SH",
  "raw": { "dates": ["2026-10-23"], "open": [1500.0], "high": [1512.0], "low": [1490.0], "close": [1505.5], "volume": [1234567] },
  "qfq": { "dates": ["2026-10-23"], "open": [1500.0], "high": [1512.0], "low": [1490.0], "close": [1505.5], "volume": [1234567] },
  "hfq": { "dates": ["2026-10-23"], "open": [1500.0], "high": [1512.0], "low": [1490.0], "close": [1505.5], "volume": [1234567] }
}
```

- 三组序列的 `dates` 必须完全等长（同一交易日集合），缺失文件的组返回六个空数组。
- `volume` 三组共用不复权成交量（与现有 `parquet_reader` 口径一致）。
- 文件不存在 / 区间无数据 → 三组均返回空数组，200，不返回 404。

### 5.2 指数日K

```
GET /api/v1/market/index/sh000300/kline?from=2026-01-01&to=2026-10-25
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | path | 是 | **必须带市场前缀**：`sh000300`、`sz399001`（纯数字无法区分沪深，直接 400 `BAD_REQUEST`） |
| `from` / `to` | string | 否 | 同上 |

响应 200：

```json
{
  "schemaVersion": 1,
  "code": "sh000300",
  "name": "沪深300",
  "market": "SH",
  "dates": ["2026-01-02"],
  "open": [3960.0],
  "high": [4001.2],
  "low": [3950.1],
  "close": [3980.12],
  "volume": [123456789]
}
```

- 指数无复权，只有一列 `close`；`name` 未知时为空字符串。
- 无文件 / 无数据 → 六个数组均为空，200。

### 5.3 数据集新鲜度

```
GET /api/v1/market/datasets
```

响应 200：

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-10-25T02:30:00Z",
  "items": [
    { "name": "平台日K数据", "type": "日K", "latestDataDate": "2026-10-24", "lagDays": 1, "fileCount": 5230 }
  ]
}
```

| 字段 | 类型 | 语义 |
|---|---|---|
| `latestDataDate` | string | 实际扫描到的最新数据日期 `YYYY-MM-DD`；无数据为 `""` |
| `lagDays` | int \| null | 相对最近交易日的滞后天数；无法计算为 `null` |
| `fileCount` | int | 实际文件数 |

数值必须来自真实文件扫描，不得给出估算或占位值。

## 6. 缓存与降级

| 层 | 策略 |
|---|---|
| 服务端 | 直读 SQLite / Parquet，本期不加进程内缓存（`stock` 表量级 5k，SQLite 查询 < 50ms）；后续如需再加 |
| 客户端 | 快照与日K按 `key + 区间` 缓存到 AsyncStorage，带 TTL；TTL 内不发请求 |
| 降级 | 请求失败或超时 → 读缓存并标注「离线缓存，数据截至 generatedAt」；无缓存 → 明确提示未连接行情，**不得静默返回空结论** |
| 刷新 | 设置页可强制刷新股票字典；请求失败不清空旧缓存 |

## 7. 错误约定

统一错误体：

```json
{ "code": "RANGE_TOO_LARGE", "message": "查询区间超过 3650 天，请缩小范围", "detail": null }
```

| HTTP | `code` | 触发 |
|---|---|---|
| 400 | `BAD_REQUEST` | 参数格式错误、缺少市场前缀的指数代码 |
| 404 | `NOT_FOUND` | 仅用于路径资源不存在（本协议接口基本不用；行情空数据走 200） |
| 422 | `VALIDATION_ERROR` | 语义校验失败（`from > to`） |
| 422 | `RANGE_TOO_LARGE` | 区间超限 |
| 500 | `INTERNAL_ERROR` | 未捕获异常 |

- `code` 是客户端分支依据；`message` 可直接展示给用户，中文，禁止包含本地绝对路径、文件名、堆栈。
- `detail` 可选，用于开发期调试，客户端不得依赖其结构。

---

## 8. 分页与增量

- 仅股票搜索有 `limit`，无 `offset`（个人场景，200 条足够）。
- 股票字典不做增量接口，全量快照 + `generatedAt` 比对。
- 行情按日期区间请求，不做增量游标。

---

## 9. 兼容策略

1. 只允许**新增可选字段**；客户端必须容忍未知字段。
2. 字段改名、改类型、改语义、改默认值 → 提升 `schemaVersion` 并新增路径版本（`/api/v2`），旧版本至少保留一个发布周期。
3. 数组追加新元素不影响兼容；若改变元素必填字段，按第 2 条处理。
4. 实现与本文不一致时**以本文为准**；确需偏离先改本文再改代码。

- [ ] 错误响应不含本地绝对路径。
