# 0005 复权口径：只存后复权因子，跨日比较统一用后复权序列

- 状态：已接受
- 日期：2026-11-18

## 背景

BaoStock 采用涨跌幅复权法。其官方说明给出的因子定义（除权日当天）为：

- 后复权因子 = 前一天收盘价 ÷ 当期前收，上市首日为 1，此后累积递增
- 前复权因子 = 当期前收 ÷ 前一天收盘价，最近一次除权日后为 1

使用方式是查表：取 `≤ 目标日期` 的最近一条因子相乘。

关键性质：**前复权因子以「最近一次除权」为基准**，每发生一次新的除权，全部历史行的前复权因子都会变小，对应的前复权价也整体变化；而后复权因子是只增不改的累积值，新除权只追加一行。

两者可互相换算：`前复权因子 = 后复权因子 ÷ 最新后复权因子`。

## 决策

1. **入库只存后复权因子**（以及除权日期），不存前复权因子；**前复权不计算、不对外提供**。
2. 因子表按除权事件追加，历史行永不回写；源文件中旧行的前复权因子发生变化时直接忽略。
3. 跨日价格比较统一使用**后复权序列**（原始价 × 当日后复权因子）。
4. 日涨跌幅一律直接使用源字段 `pctChg`，不用 `close ÷ 前一日 close` 自行计算——前者在除权日已按调整后的 `preclose` 计算。
5. 成交量与量比不涉及复权，规则求值时直接使用原始成交量。
6. P0 的四类规则全部为相对指标，不接受绝对价格阈值：突破 = 收盘价高于前 N 日最高收盘价；超跌 = 相对前 N 日最高收盘价的回撤比例；均线 = 收盘价与 MA(N) 的关系；放量/缩量 = 量比。这样无需在界面上做复权价与真实价的换算。
7. 展示层展示什么口径由界面决定，但计算层只认后复权序列与 `pctChg`。

## 备选方案

| 方案 | 未采用的原因 |
|---|---|
| 存前复权因子 | 每次新除权都要回写全部历史因子行与前复权价，写入成本随历史长度增长 |
| 直接存前复权价 / 后复权价 | 价格序列与因子解耦后无法重新推导；且前复权价随新除权全量失效 |
| 存「除权事件」并自行滚乘因子 | 源数据已直接给出各除权日的因子绝对值，滚乘会引入自算误差 |
| 允许规则输入绝对价格阈值 | 后复权价与真实价位相差倍数级，需要双向换算，容易出错且用户难以理解 |

## 后果

- 后复权价是累积放大的数值（例如真实 15 元的股票可能显示 110 元），任何对外的绝对价位都必须先换算到展示口径。
- 若将来需要「跌破某价位」这类绝对价格规则，必须新增一层口径换算，属于结构性改动。
- 源站若修正历史因子（后复权因子本身变化），仍会触发该标的的修复型重算；但因子上只追加的常态下不会发生。
- 复权因子文件只包含发生除权的标的，未发生除权的标的在因子表中无记录，读取时需按「无记录即因子为 1」处理。

## 修订记录

- 2026-11-18：确认源因子文件是**当日除权标的清单**（样例 2026-06-12 共 92 行、2025-02-14 共 3 行，行数随分红季波动），不是全市场快照。据此新增两点：
  1. 后复权因子改由日 K 推导：`因子(t) = 因子(t-1) × 昨日不复权收盘 ÷ 当日 preclose`。用官方示例验证：`15.47 ÷ 11.75 = 1.3166 = 9.385732 ÷ 7.128788`。
  2. 因子文件降级为**对账**用途，不作主数据源。原因：因子文件必须逐日无缺收集，漏一天则该日除权事件永久丢失（后续文件不会重复出现历史事件）；而日 K 的横截面可任意重建。本产品的规则全部是相对指标，因子基准取 1 还是取真实上市首日不影响判断结果。
- 2026-11-19：**取消前复权的读取时推导**，改为完全不计算前复权。依据 baostock 官方文档（`localdatafactorInfo.md` 第四、五步）：官方同时维护 `foreAdjustFactor` 与 `backAdjustFactor`，但其增量方式是对当日除权标的「删除该标的全部历史因子行 → 重拉全历史替换」，说明前复权因子必须随新除权整体重写，而后复权重拉后数值不变。既然 P0 的规则全部是相对指标、展示只需真实价，前复权无任何使用场景。
