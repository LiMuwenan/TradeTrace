## 要做什么

每个交易日收盘求值后，生成一份当日汇总，作为「当天什么都没触发」时的兜底触达，以及在 Web 上回看当日全貌的入口。

## 验收标准

- [ ] 每个交易日生成一份日报，**无论当天是否产生预警都生成**
- [ ] 日报包含：当日触发清单、接近阈值但未触发的清单、自选涨跌概览、数据日期
- [ ] 接近阈值项按 05 票定义的口径计算（差距在阈值 20% 以内）
- [ ] 日报通过与预警相同的通知通道投递（ntfy，失败降级邮件）
- [ ] Web 可回看历史日报，按日期列表进入
- [ ] 日报内容不可被后续求值改写（同一天重跑只更新未投递的草稿，已投递的保留原文）
- [ ] 日报带「不构成投资建议」提示

## 备注

- 日报与逐条预警是两条独立的触达路径：逐条负责「尽早知道」，日报负责「不漏」
- 日报生成失败不应影响已发出的逐条预警
- 邮件正文用纯文本或简单 HTML 皆可，不要求 PDF 导出（P0 范围外）
