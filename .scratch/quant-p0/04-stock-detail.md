## 要做什么

从自选列表点进任一标的，看到它的日 K 线与均线，用于人工判断规则触发是否合理。

## 验收标准

- [x] 个股详情页展示日 K 线图，可切换时间范围（至少 3 个月 / 1 年 / 全部）
- [x] 叠加均线：5 / 10 / 20 / 60 日，可单条开关
- [x] 均线基于**后复权序列**计算，避免除权造成虚假穿越
- [x] 价格显示口径明确：图上展示的是后复权价，并在页面标注「价格为后复权」
- [x] 停牌日不参与均线计算，也不会在图上画成一根平直线
- [x] 页面展示最近交易日、收盘价、涨跌幅、以及该标的是否在自选中

## 备注

- 数据来源为 02 提供的「按标的读取序列」接口，本票不新增取数逻辑
- 移动端不做此页（App 只做预警两页），点击后跳浏览器打开本页
- 技术指标全集（MACD、RSI 等）不在 P0 范围
- **2026-11-26：本票顺延到下一迭代**，本迭代只做预警最小闭环（05 → 07 → 08）。见 ADR `0006-p0-scope-convergence.md`；票面范围与验收标准不变

**实施记录**（2026-11-26）：聚合在 `app/services/stock_detail.py`，路由 `GET /stocks/{code}/detail?range=3m|1y|all`（`app/api/stocks.py`，`/stocks/search` 一并从自选路由迁入），前端 `web/src/components/StockDetailPage.vue` + echarts。

**四处实现判断**：

- 均线先在**全量序列**上算、再和展示区间一起裁剪。若先裁区间再算，MA60 在「3 个月」视图里会从 None 起步，图上看不到线。
- 停牌行在服务层就被剔除，前端拿到的 `items` 里根本没有它——这样「不画平线」是数据结构保证的，不依赖图表配置。
- `latest` 同时给 `close`（后复权，与图一致）和 `rawClose`（不复权）。自选页展示的是不复权价，只给一个数会让用户以为两个页面数据不一致。
- echarts 走路由懒加载：首屏包 293KB，详情页单独 583KB，不把图表成本摊给每个用户。
