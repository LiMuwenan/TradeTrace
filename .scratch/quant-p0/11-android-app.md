## 要做什么

手机 App 只做「消费」不做「配置」：看预警列表、看某条预警的触发快照。个股详情、规则配置等留在 Web，点按钮跳浏览器打开。

## 验收标准

- [ ] App 可展示预警列表，按时间倒序，区分已读与未读
- [ ] 可在 App 内把单条预警标记为已读，状态与 Web 端一致
- [ ] 点开某条预警看到触发快照：标的、规则、触发值、阈值、数据日期
- [ ] 页面提供入口跳转到 Web 的个股详情
- [ ] 未连接家庭网络时，明确提示「当前不在内网」，不反复重试、不卡死白屏
- [ ] App 与 Web 使用同一套后端接口，不另开后端专用接口
- [ ] 页面带「不构成投资建议」提示

## 备注

**分工原则**：Web 负责配置与深度分析，App 负责随身查看。不要在 App 复刻规则配置、选股、回测。

**推送说明**：P0 的提醒由 ntfy 承担，App 不实现自有推送通道；因此 App 退到后台收不到服务端消息是预期行为，预警以列表形式完整保留在服务端。

**技术**：Expo/RN，与仓库已有移动端经验一致，但不复用其源码。

**排期**：2026-11-26 起**移出 P0，标注 P1**。ADR 0003 决策 4 的双端分工结论不变，只推迟交付时点；P0 期间手机侧由 ntfy 客户端承担触达，Web 承担阅读。见 ADR `0006-p0-scope-convergence.md`。
