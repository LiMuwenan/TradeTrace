## 要做什么

用户在 Web 上自助创建、修改、停用预警规则，不需要改配置文件或写 SQL。

## 验收标准

- [ ] 可新建规则：选规则类型、标的范围、时间窗、阈值
- [ ] 可修改已有规则的阈值与时间窗，修改后从下一个求值日生效，历史预警不受影响
- [ ] 可停用规则：停用后不再参与求值；历史预警记录仍然保留可查
- [ ] 表单校验：时间窗不得小于 2；阈值限定在合理区间（放量 > 0、超跌在 0～100% 之间），越界时给出具体提示
- [ ] 规则列表展示：类型、标的范围、关键参数、启用状态、最近一次触发时间
- [ ] 新建与修改后能看到该规则覆盖了多少只标的

## 备注

- 编辑体验以表单为主，不做自然语言规则生成，也不做公式编辑器
- 标的范围 P0 只支持「全部自选」与「指定单只标的」两种
- 规则与预警记录的关系：修改规则不追溯历史预警；历史预警保留当时的快照值
