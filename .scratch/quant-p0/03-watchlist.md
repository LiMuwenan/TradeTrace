## 要做什么

用户能维护自己的自选清单，并在一个列表里看到它们的最新行情。自选是后续所有规则求值的默认标的范围。

## 验收标准

- [x] 可按代码或名称搜索标的并加入自选；已存在的不会重复加入，重复操作不报错
- [x] 可从自选中移除标的
- [x] 自选列表展示：代码、名称、最新交易日、收盘价、当日涨跌幅
- [x] 涨跌幅直接使用数据源的涨跌幅字段，不由收盘价与昨收自行计算（除权日会算错）
- [x] 自选为空时给出明确引导，不显示空白表格
- [x] 自选数据持久化，服务重启后仍存在

## 备注

- 单用户场景，无需登录与多租户；自选是全局唯一一份
- 默认按添加顺序展示，支持手动排序可作为后续增强，不在本票范围
- 涨跌幅口径：数据源当日字段；停牌标的显示为「停牌」而非 0%
