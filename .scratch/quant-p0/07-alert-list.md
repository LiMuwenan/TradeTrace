## 要做什么

用户在 Web 上查看历史预警，能分辨哪些还没看过，并点开看触发时的具体情况。

## 验收标准

- [ ] 预警列表按时间倒序、分页展示
- [ ] 列表项展示：标的代码与名称、规则名称、触发值、阈值、数据日期、已读/未读状态
- [ ] 可切换单条已读/未读；可一键全部标记已读
- [ ] 可按已读状态、标的、规则类型筛选
- [ ] 点击进入详情，展示触发快照：触发时指标值、阈值、使用价格、数据日期、规则参数
- [ ] 详情页标注「本内容仅为数据分析，不构成投资建议」
- [ ] 顶部展示未读数量

## 备注

- 已读状态是单用户全局状态，不做多用户隔离
- 同一标的同一天可能有多条不同规则的预警，列表需逐条展示
- 该页面在移动端不做，App 侧由后续票实现
