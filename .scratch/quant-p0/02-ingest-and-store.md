## 要做什么

打通「原始数据 → 可查询的日 K 序列」这条链路。核心是**单一入口** `ingest_day(交易日, 数据来源)`：历史导入与每日增量都走同一条代码路径，只是数据来源不同（历史 CSV 目录 / 实时接口）。

导入后，任意标的都能查到原始价与后复权价，并在 Web 上看到数据覆盖情况。

## 验收标准

- [ ] 存在唯一的数据写入入口；任何数据入库都必须经过它，没有第二条写路径
- [ ] 支持两种数据来源：历史按日横截面 CSV 目录、每日实时接口；两者产出同一种中间结构（当日全市场日 K + 当日除权清单）
- [ ] 导入历史 CSV 后，可查询任意标的的逐日序列，后复权价 = 原始价 × 因子
- [ ] 每日增量可把当日数据并入当年分区；重复导入同一交易日不产生重复行（按标的+日期覆盖）
- [ ] 因子只使用后复权因子并前向填充：当日未除权的标的沿用上一交易日的因子值
- [ ] 写入前校验：因子随时间单调不减；单次除权的因子增量落在 [0.5, 3]；不合格拒绝写入并报错
- [ ] 写入采用原子替换，进程中断不产生半个年份文件
- [ ] 实时接口抓取后，按与历史目录相同的格式额外归档一份原始 CSV
- [ ] Web 数据状态页展示：总行数、日期范围、缺失交易日列表、最近一次导入结果

## 备注

**存储形态**：按年份单文件分区（`<年份>.parquet`，内含当年全市场所有标的），按 (标的, 日期) 排序写入；不使用「每标的一文件」。

**数据规模参照**：约 5200 只 × 250 交易日 ≈ 每年 130 万行，20 年约 2600 万行。

**字段与格式**：
- 标的代码格式统一为 `sh.600000` / `sz.000001`
- 日 K 字段取自数据源当日接口的 18 列（含 `preclose`、`pctChg`、`turn`、`tradestatus`、估值列）
- 停牌行（`tradestatus=0`）**保留入库**，但价格字段无效、成交量为空，规则求值时必须排除
- 只存不复权 OHLCV + 每行的后复权因子；**不存前复权数据、不存前复权因子**

**为什么只存后复权因子**：后复权以上市首日为基准，新除权不改变历史行；前复权以「最近一次除权」为基准，每次新除权都会改写全部历史。存前复权会导致历史重写。

**因子来源**：以数据源每日提供的除权清单为准（一次调用拿全市场当日除权标的），不靠日 K 反推；若两者冲突以官方值为准并记录告警。

**索引不在本票范围**：指数不包含在全市场接口返回中，P0 暂不纳入，如需要另开票。
