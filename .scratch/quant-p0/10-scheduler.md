## 要做什么

把前面各票串成每天自动运行的流水线，用户不需要每天手动点任何按钮，同时保留手动补跑某个交易日的能力。

## 验收标准

- [ ] 每个交易日收盘后自动执行：增量取数 → 规则求值 → 通知推送 → 生成并投递日报
- [ ] 非交易日不执行，也不产生空的日报或预警
- [ ] 维护增量游标：记录最后一个成功入库的交易日，下次从其后开始
- [ ] 某天失败时留下缺口记录，次日自动尝试补齐；缺口可手工触发补跑
- [ ] 可手动指定任意交易日重跑整条流水线，重复执行不产生重复预警
- [ ] Web 运行记录页展示：每次运行的日期、各阶段耗时、成功/失败、失败原因
- [ ] 任一阶段失败不影响已完成的阶段（例如取数成功但通知失败，取数结果仍保留）

## 备注

**每日取数调用量**：全市场日线一次 + 当日除权清单一次，共两次批量调用；逐标的循环取数在设计上被排除。

**数据缺口**：缺口是指「应为交易日但未成功入库」的日期，不是指单只标的停牌。停牌是正常数据，不算缺口。

**不做**：盘中实时求值、交易日历对接（是否交易日以数据源返回的当日数据是否为空来判定）。
