## 1. 样本结论摘要

| 发现 | 影响 |

| 单一版式：浙商证券红头版，表头为 `金额/费用` | 可按固定结构解析，但仍需用表头文字定位，避免 UI 改版后错位 |

| 买入金额为负、卖出为正；方向文字明确 | 方向以文字前缀为准，金额符号只作交叉校验 |

## 2. 页面结构

从上到下：

```
状态栏（时间、信号、电量）
顶部标题栏：返回 | 对账单 | 账户（“浙商证券 *4768”） | 导出/筛选
筛选提示条：当前页面处于已筛选中，按类型筛选了“买入”、“卖出”、“新股新债”、“银证转账”、“分红派息”
时间范围 Tab：本月 / 近三月 / 近半年 / 今年 / 全部 / 自定义
收益摘要卡（可折叠）：盈亏、收益率、上证、平均仓位、成功率、交易股票数、交易笔数、盈利/亏损股票数、持股天数
表头：操作 | 价格/数量 | 金额/费用
月份分组行：2026-10 | 月度盈亏 | 涨跌幅 | 上证涨跌幅
交易行块：操作名 + 买/卖/红/新/银徽标 + 日期时间 | 价格 + 数量 | 金额 + 费用
空状态：无符合条件的流水数据
页脚：更多数据请调整时间范围进行查看 / 功能帮助 / 意见反馈
```

解析锚点：

- 以表头文字 `操作`、`价格/数量`、`金额/费用` 定位表格区域与列边界。
- 表格上方内容（摘要）一律忽略，不参与导入。
- 表格下方页脚忽略。
- 筛选提示条可用于提示“当前截图已筛选，可能不含全部流水”，但不阻挡导入。

## 4. 行语法

### 4.1 行块结构

每个交易行在视觉上占三行：

```
第 1 行：操作名（可能带“证券”前缀） + 买卖徽标 + 日期时间
第 2 行：价格（3 位小数） + 数量（整数）
第 3 行：金额（2 位小数） + 费用（2 位小数）
```

OCR 输出后，按纵坐标把三行聚成一个行块；不能按文本流顺序直接拼接。

### 4.2 操作名语法

| 正则（示意） | 类型 | 处理 |
|---|---|---|
| `^(证券)?买入-(.+)$` | 买入 | 股票名 = 捕获组 |
| `^(证券)?卖出-(.+)$` | 卖出 | 股票名 = 捕获组 |
| `^股息入账-(.+)$` | 股息 | 正股息 |
| `^股息红利税补缴-(.+)$` | 股息（负） | 负股息，note 标记“红利税补缴” |
| `^申购配号-(.+)$` | 非交易 | 跳过，导入结果中提示 |
| `^银行转(存|取)$` | 非交易 | 跳过，导入结果中提示 |
| `^\d{4}-\d{2}$` | 月份分组 | 跳过，用于确定年份 |
| `^无符合条件的流水数据$` | 空状态 | 跳过 |
| `更多数据请调整时间范围进行查看` 等 | 页脚 | 跳过 |

### 4.3 股票名称归一化

- 去除除权除息前缀：`XD`、`XR`、`DR`（如 `XD工商银行` → `工商银行`）。
- 去除风险/新股标识：`ST`、`*ST`、`N`、`C`、`U`（按前缀/后缀位置判断，避免误伤名称本身）。
- 全角/半角、空格、连字符统一。
- 用归一化后的名称查本地股票字典；查不到则要求用户手动选择，不创建新股票。
- 同一名称在一批截图里重复出现时，复用同一个映射结果。

### 4.4 日期与时间

- 行内只有 `MM-DD HH:mm`；年份从所属月份分组 `YYYY-MM` 获取。
- 跨年边界：每一行必须用其所属分组年份，不能用全局年份。
- 校验：日期不得晚于今天；时间允许 `00:00–23:59`；股息行的时间可能是 `16:00`（入账时间），仍保留。

## 5. 字段映射

### 5.1 买入 / 卖出

| 目标字段 | 来源 | 规则 |
|---|---|---|
| `type` | 操作名前缀 | `买入` / `卖出` |
| `date` | 行内 MM-DD + 分组年份 | 统一 `yyyy-MM-dd` |
| `price` | 价格列 | 3 位小数；> 0 |
| `shares` | 数量列 | 买入为正，卖出为负；> 0 的数量 |
| `commission` | 费用列 / 金额反推 | 见下 |
| 股票 | 操作名中的名称 | 名称→代码映射 |

费用逻辑：

- 金额已含费用：
  - 买入：`|金额| = price × shares + commission` → `commission = |金额| − price × shares`
  - 卖出：`金额 = price × shares − commission` → `commission = price × shares − 金额`
- 用该式反推并与费用列交叉校验；误差 > 0.02 时标记“待确认”。
- 费用列应为数值；异常或缺失值标记“费用待确认”，不得静默当作真实 0。
- 方向以文字为准；金额符号只作辅助校验。

### 5.2 股息入账

| 目标字段 | 来源 | 规则 |
|---|---|---|
| `type` | 固定 | `股息` |
| `shares` | 数量列 | `0` |
| `price` | 价格列 | **不是成交价**，置 0；可把原值写入 `note`（如“分红参数 8.580”） |
| `dividend` | 金额列 | 正数 |
| `commission` | 费用列 | 通常 0；有值则记录并校验 |

> 价格列在股息行显示的是分红方案参数（疑似每 10 股派息额），与数量 0 不构成 `price × shares`；**绝不能当作成交价**。

### 5.3 股息红利税补缴

- 归入 `type = 股息`，`dividend` 为负数（如 `-16.89`），`note` 写明“红利税补缴”。
- `shares = 0`，`price = 0`。
- 与正股息分开保留，便于后续核对；不要合并成一条。
- 需要确认现有表单/统计是否允许负股息；若不允许，先扩字段或调整校验（改口径需同步 `stats.test.ts`）。

### 5.4 非交易流水

| 类型 | 处理 |
|---|---|
| `银行转存` / `银行转取` | 跳过；结果页提示“已忽略 N 条银证转账” |
| `申购配号` | 跳过；结果页提示“已忽略 N 条新股申购” |
| 月份分组 / 空状态 / 页脚 | 跳过 |

不把银证转账计入收益，避免污染交易统计。

## 6. 校验与去重

### 6.1 行级校验

- 股票名可映射；否则标记待人工选择。
- 买入/卖出：`price > 0`、`shares > 0`、日期合法。
- 金额与价格×数量在费用容差内；不一致则高亮。
- 费用 ≥ 0；异常值标记待确认。
- 股息：金额可正可负；正股息金额 > 0；税补缴金额 < 0。
- 行块字段缺失（被截断/遮挡）→ 不自动勾选。

### 6.2 跨图去重

同一账户的多张截图会大量重叠（同一批流水被多次截取），必须去重：

```
dedupeKey = hash(归一化股票名 + 日期 + 类型 + shares + price(±0.01) + commission(±0.5))
```

- 同一批导入内去重。
- 与已有交易去重。
- 命中重复默认跳过，可在确认页强制导入。
- 图片级幂等：同一图片哈希重复导入不产生新记录。

### 6.3 账户识别

- 头部可读到 `浙商证券 *4768`。
- 若本地存在匹配账户（名称或备注包含券商名/尾号），自动预选；否则要求用户选择。
- 一批截图默认归属同一账户；用户在确认页可统一修改。
- 不保存完整资金账号；只保留券商名与掩码尾号用于匹配。

## 7. 遮挡、截断与隐私

| 情况 | 处理 |
|---|---|
| 状态栏、通知图标 | 裁剪掉顶部状态栏区域 |
| 顶部/底部行被截断 | 跳过不完整行，或标记“需补充截图” |
| 深色主题 | 亮度归一化后识别；不依赖颜色判断方向 |
| 大面积遮挡导致行不可读 | 该行不进入候选，提示重新截图 |
| 账户名/资金等隐私 | 只输出交易字段；账户仅保留券商名与掩码尾号；不保存原图长期副本 |

## 8. 模板版本与识别

模板 ID：

| ID | 适用 |
|---|---|
| `ths_zheshang_v1` | 当前浙商证券版式：`金额/费用`、带符号金额、`YYYY-MM` 分组 |
| `ths_generic_v1` | 兜底：仅按三列表头与行块结构解析，字段不确定时置空 |

模板检测顺序：

1. 读表头文字：`金额/费用` → 浙商模板。
2. 读账户副标题：`浙商证券` 进一步确认。
3. 读月份分组格式：`YYYY-MM` → 确认。
4. 不匹配 → generic，并降低置信度。

模板规则与 OCR 引擎解耦：模板只消费“文本行 + 坐标”，可用固定 fixture 单测。

## 12. 验收标准

- 用当前 17 张样本（浙商证券版式）跑通：买入、卖出、股息入账、税补缴正确解析；银证转账/申购配号被跳过并提示。
- 关键字段（日期、方向、名称、价格、数量、费用）字段级准确率 ≥ 95%；股息金额与税补缴符号正确。
- 费用异常或缺失时不被静默当作 0；有明确警告。
- 同一批 17 张截图重复导入，不新增重复记录。
- 状态栏内容不进入候选；截断行不自动勾选。
- 股票名称可映射到代码；`XD/XR/DR/ST` 前缀处理正确。
- 全程离线，无截图上传。
