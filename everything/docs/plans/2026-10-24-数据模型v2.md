# everything 数据模型 v2 实施计划

> 对应产品规划：`docs/交易记录与复盘产品规划.md` 第 4 章 P0。
> 范围：只改 `everything/src`、测试与文档；不改 `lianghua/`，不对接后端。

**目标**：把交易数据从“数字自增 ID + 物理删除 + 整包覆盖同步”升级为“UUID + 软删除 + 实体级合并”，为 OCR 导入、行情对接、行为分析打地基。

**架构**：领域模型（types）→ 迁移（migrate）→ 纯函数变更（state）/ 合并（merge）→ 持久化（storage）/ 仓库门面（repository）→ Context 与页面。统计口径 `stats.ts` 保持唯一权威实现，只增加墓碑过滤。

**技术栈**：TypeScript strict、Vitest、AsyncStorage、Expo 58。

## Task 2：模型 v2 与费用口径

**Files:** Modify `src/data/types.ts`; Test `src/data/types.test.ts`

模型：

```ts
export type TransactionSource = 'manual' | 'ocr' | 'import'
export interface SourceRef { imageHash: string; templateId: string; lineNo?: number }
interface EntityMeta { id: string; createdAt: string; updatedAt: string; deletedAt?: string; legacyId?: number }
export interface Account extends EntityMeta { name: string }
export interface Stock extends EntityMeta { accountId: string; name: string; code: string }
export interface TransactionTrade extends EntityMeta {
  stockId: string; date: string; time?: string; price: number; shares: number
  commission: number; type: TransactionKind; dividend?: number
  source: TransactionSource; sourceRef?: SourceRef; dedupeKey: string
  expectedRange?: string; expectedBuyLow?: number; expectedBuyHigh?: number
  expectedSellLow?: number; expectedSellHigh?: number; note?: string
}
export interface TTrade extends EntityMeta {
  buyTransactionId: string; sellTransactionId: string; shares: number
}
export interface TradeState {
  schemaVersion: 2; deviceId: string; revision: number; updatedAt: string
  accounts: Account[]; stocks: Stock[]; transactions: TransactionTrade[]; tTrades: TTrade[]
}
export function createEmptyState(deviceId = '', updatedAt = ''): TradeState
export function computeDedupeKey(code: string, input: Pick<TransactionTrade, 'date'|'type'|'shares'|'price'|'commission'|'dividend'>): string
```

`computeDedupeKey` 规则：`code|date|type|shares|price.toFixed(2)|commission.toFixed(2)`；股息用 `dividend.toFixed(2)` 替代价格与手续费。

测试：负股息 `transactionCost` 返回负数；`dedupeKey` 对价格/手续费尾差归一化稳定；不同代码/日期/方向键不同。

## Task 5：实体合并

**Files:** Create `src/data/merge.ts`、`src/data/merge.test.ts`

```ts
export type EntityKind = 'account' | 'stock' | 'transaction' | 'ttrade'
export interface MergeConflict { entity: EntityKind; id: string; localUpdatedAt: string; remoteUpdatedAt: string; winner: 'local' | 'remote' }
export interface MergeResult { state: TradeState; conflicts: MergeConflict[] }
export function mergeStates(local: TradeState, remote: TradeState, now: string): MergeResult
```

规则：按 ID 取并集；`updatedAt` 新者胜；时间相同且一方有 `deletedAt` 则删除胜；双方都有且内容不同记一条冲突；合并后 `revision = max+1`、`updatedAt = now`、`deviceId` 用本机。

测试：两端各新增交易 → 合并后都在；远端删除不被本地旧副本复活；远端更新更新字段；冲突条数与 winner 正确；重复合并幂等。
